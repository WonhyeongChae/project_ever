# QR/NFC 기반 위치·행동 데이터 수집 인프라

## 한 줄 요약

에버랜드 주요 지점에 QR/NFC 체크포인트를 배치하고, 방문객이 스마트 티켓이나 앱으로 태깅할 때마다 익명 Visitor ID 기준의 위치·시간·이동 흐름 데이터를 축적하는 저비용 행동 데이터 인프라.

## 문제 정의

AI 컨시어지, 혼잡 분산, 개인화 추천, 게이미피케이션을 구현하려면 방문객이 실제로 어디를 방문했고 어떤 순서로 이동했는지에 대한 데이터가 필요함.

상시 GPS 추적이나 카메라 기반 추적은 다음 문제가 존재함.

- 개인정보 및 심리적 거부감
- 배터리 소모
- 구축 및 운영 비용
- 위치 정확도와 실내/야외 혼합 환경 문제

## 핵심 아이디어

에버랜드 주요 분기점과 시설에 QR/NFC 체크포인트를 설치함.

설치 후보:

- 주요 분기점
- 어트랙션 입구
- 식당
- 포토존
- 공연장
- 주요 랜드마크

사용자가 스마트 티켓 또는 에버랜드 앱으로 태깅하면 해당 이벤트를 익명 Visitor ID와 연결함.

수집 가능한 데이터:

- 현재 위치
- 방문 시간
- 이동 순서
- 체크포인트 간 이동시간
- 체류시간 추정
- 다음 목적지
- 그룹 여부

예시 동선:

```text
입장
↓
판다월드 QR/NFC
↓
사파리 QR/NFC
↓
식당 QR/NFC
↓
T익스프레스 QR/NFC
```

## 생성 가능한 데이터 구조

방문객 단위 이동 로그를 축적하면 시설을 노드, 이동을 엣지로 갖는 동선 그래프 생성 가능함.

예시 분석:

- 판다월드 방문 이후 어떤 시설로 가장 많이 이동하는지
- 시간대별 특정 구간의 이동량 변화
- 특정 시설 방문 전후 체류시간 변화
- 그룹 방문객과 개인 방문객의 동선 차이
- 행사나 퍼레이드 전후 이동 패턴 변화

즉, AI가 활용할 수 있는 `Where / When / Movement` 데이터 확보 가능함.

## AI 적용 가능성

### 1. 동선 예측

현재 위치와 과거 방문 패턴을 바탕으로 다음 이동 후보 예측 가능함.

### 2. 혼잡 분산

특정 경로로 방문객이 집중되는 패턴을 사전에 감지해 다른 시설이나 경로 추천 가능함.

### 3. AI 컨시어지

현재 체크포인트 위치를 확정값으로 활용해 일정과 다음 이동 경로를 재계산 가능함.

### 4. 게이미피케이션

QR/NFC 태깅 자체를 탐험, 퀘스트, 체크인, 수집 요소로 활용 가능함.

## 기대 효과

- 상시 위치 추적 없이 의미 있는 동선 데이터 확보
- 기존 카메라 기반 추적 대비 개인정보 부담 감소
- GPS 상시 사용 대비 배터리 부담 감소
- QR부터 시작할 경우 비교적 낮은 초기 구축 비용
- AI 컨시어지와 Quest Pass의 공통 기반 데이터 확보
- 구역별 방문 흐름과 체류 패턴 분석 가능

## 리스크 / 반론

- 사용자가 태깅하지 않으면 데이터가 누락됨
- QR 공유나 대리 스캔에 따른 노이즈 발생 가능
- 모든 이동 경로를 연속적으로 파악하는 방식은 아님
- 정확한 체류시간 계산에는 추가 데이터 또는 추정 모델 필요
- NFC 활용 시 단말 및 운영체제별 지원 범위 검토 필요
- 체크포인트가 너무 많으면 사용자 행동 부담 증가 가능

## 보완 방향

- 모든 지점이 아니라 주요 분기점과 핵심 시설 중심으로 시작
- QR을 기본 인프라로 두고 NFC를 선택적으로 병행
- 스마트 줄서기, 티켓 인증, Quest 참여 등 자연스러운 행동에 태깅을 결합
- 사용자에게 별도의 데이터 입력을 요구하기보다 서비스 이용 과정에서 자연스럽게 데이터가 발생하도록 설계

## 기존 팀 자료와의 관계

- `Everland AI Concierge`가 필요로 하는 현재 위치와 이동 흐름 데이터의 기반 인프라 역할
- `Everland Quest Pass`의 체크포인트 및 방문 인증 수단으로 재사용 가능
- 기존 아이디어를 대체하기보다 여러 AI 서비스를 가능하게 하는 공통 데이터 레이어에 해당함

## 추가 조사 필요

- 에버랜드 현재 QR/NFC 및 스마트 티켓 사용 범위
- 기존 앱에서 확보 가능한 위치/방문 데이터 범위
- QR/NFC 태깅 데이터를 이용한 실제 테마파크·리테일 사례
- 익명 Visitor ID의 보관 기간 및 개인정보 처리 기준
- 태깅 참여율을 높일 수 있는 UX 설계
