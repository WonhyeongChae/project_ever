# Everland Quest Pass

## 한 줄 요약

에버랜드 전체를 하나의 게임 맵으로 보고, 실제 방문·탑승·탐색 행동을 AI가 개인화 퀘스트와 보상으로 연결해 체류시간과 재방문 동기를 높이는 게이미피케이션 서비스.

## 문제 정의

에버랜드 방문 경험은 인기 어트랙션 중심으로 반복되기 쉬우며, 비인기 구역이나 시즌 콘텐츠는 방문 유도가 어렵고 재방문 이유도 약해질 수 있음.

단순 스탬프 투어나 쿠폰 지급은 다음 한계가 존재함.

- 반복성이 높음
- 개인화 부족
- 방문객이 앱을 계속 확인해야 할 수 있음
- 현금성 보상 의존 시 운영비 증가

## 핵심 아이디어

입장 시 방문객에게 랜덤 또는 개인화 퀘스트를 지급함.

예시:

- 오늘 3개 Zone 방문
- 특정 캐릭터 조형물 찾기
- 숨은 QR/NFC 체크포인트 5개 발견
- 특정 시간대 퍼레이드 관람
- 동물원 미션 완료

AI는 사용자의 행동, 방문 진행도, 혼잡도, 남은 체류시간을 보고 다음 퀘스트의 난이도와 위치를 동적으로 조정함.

## 게임 루프

```text
입장
↓
개인/파티 Quest 생성
↓
실제 에버랜드 방문 행동 수행
↓
QR/NFC/티켓/시설 이용으로 자동 또는 반자동 인증
↓
AI가 다음 Quest 조정
↓
보상·배지·진행도 획득
↓
재방문 시 새로운 시즌/연속 Quest 제공
```

## 보상 설계

현금성 보상에 과도하게 의존하지 않는 것이 핵심임.

가능한 보상:

- 디지털 배지
- 캐릭터 스킨
- 포토 프레임
- 소액 할인 쿠폰
- 한정 굿즈 구매 권한
- 시즌별 랭크
- 파티 협동 업적
- 재방문 시 이어지는 진행도

## AI 적용 가능성

### 1. 개인화 Quest 생성

연령대, 동행 유형, 선호 콘텐츠, 남은 시간에 따라 퀘스트를 다르게 구성함.

### 2. 난이도 조절

사용자가 너무 빠르게 또는 느리게 진행하면 Quest 난이도와 목표 수를 조정함.

### 3. 혼잡도 연계

혼잡한 시설에 사용자를 더 보내는 대신, Quest 목적지를 다른 구역으로 분산시켜 자연스럽게 군중 분산 가능함.

### 4. 시즌 콘텐츠 생성

계절, 축제, IP 이벤트에 맞춰 신규 Quest를 빠르게 생성 가능함.

## 기대 효과

- 체류시간 증가
- 비인기 구역 방문 유도
- 시즌 이벤트 참여 증가
- 재방문 동기 강화
- 기존 공간을 신규 콘텐츠처럼 재활용 가능
- AI 기반 개인화 경험 제공

## 리스크 / 반론

- Quest가 숙제처럼 느껴질 수 있음
- 앱 확인 빈도가 높으면 현장 몰입 저하 가능
- 보상이 과도하면 운영비 증가
- QR 공유 또는 대리 인증 가능성
- 어린이/고령자/비게이머에게 복잡하게 느껴질 가능성

## 보완 방향

### Invisible Quest

사용자가 매번 미션을 확인하고 인증하는 구조보다, 실제 방문 행동 자체가 자동으로 진행 조건이 되도록 설계함.

예:

```text
판다월드 방문
+ 사파리 이용
+ 퍼레이드 관람
↓
퇴장 시 "오늘의 탐험 Quest 7개 완료" 표시
```

즉, 사람이 게임을 따라가는 방식보다 자신의 하루가 게임 기록으로 변환되는 방식이 적합함.

- QR/NFC 부정 인증 방지 수준
- Quest 완료율과 체류시간 변화 측정 방법
- 시즌별 콘텐츠 운영 비용
