# Research Notes

팀원별 조사 결과 저장 위치.

## Directory rule

```text
research/
└─ <github-id>/
   └─ YYYY-MM-DD-<topic>.md
```

## 작성 원칙

- 한 파일은 하나의 중심 주제 유지
- 외부 사실은 출처 보존
- 팀 아이디어와 검증된 사실 구분
- 기존 자료와 중복되면 차이점/보강점 중심 기록
- 불필요한 원문 대화 전체 복사 금지

개인 Research Note 생성 시 `.agents/skills/research-sync/SKILL.md` 사용 권장.
