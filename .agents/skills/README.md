# Team Skills

공모전 리서치 협업용 로컬 스킬 모음.

## Skills

### research-sync
개인 조사 자료, 메모, 현재 AI 대화를 공모전용 Research Note로 정리함.

출력 위치:
`research/<github-id>/YYYY-MM-DD-<topic>.md`

### team-synthesis
팀 전체 Research Note를 비교하고 중복을 제거해 현재 아이디어 상태를 갱신함.

주요 출력:
- `synthesis/current-summary.md`
- `ideas/revenue.md`
- `ideas/gamification.md`
- `ideas/concierge.md`

### meeting-brief
현재 팀 지식을 회의용 브리프로 변환함.

주요 출력:
`synthesis/meeting-YYYY-MM-DD.md`

## 공통 원칙

- Skill은 원문 자료를 그대로 저장하는 도구가 아니라 의사결정용 지식 정리 도구임.
- 외부 사실과 팀 아이디어를 분리함.
- 출처가 있다면 반드시 보존함.
- 중복을 최소화함.
- 결론이 나지 않은 내용은 `미결정` 또는 `가설`로 표시함.
